# Template Mind repository rules

This repository is the identity-free mind inherited by every ENVOLVE world.

- Read `CLAUDE.md` before touching source.
- Identity is runtime configuration only. Never add a person, email address, phone number,
  HAM UID, grant ID, credential, or world-specific doctrine as a literal or fallback.
- Upgrade the canonical implementation already present. Do not add scaffolds, duplicate sources,
  orphan modules, cold semantic decisions, or single-shot paths around the PAI cycle.
- Every state-changing HTTP door proves its exact world server-side. Request bodies, query strings,
  and route parameters are never identity authority.
- Prove reachability and integration with focused tests, the full suite, and recursive relative-import
  checks before calling a change complete.
- Shared PAI files must preserve the declared sister-source contract with the canonical `anew` repo.
- Real receipts only. Return `ok:false` when a dependency or proof is unavailable.
- This template remains a TRUE ZERO. Operational doctrine that contains a real-world identity stays
  in its canonical runtime source and is referenced here, never copied into every inherited world.
